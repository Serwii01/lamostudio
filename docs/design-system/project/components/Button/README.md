# Button

Botón en forma de píldora para cualquier acción; la variante dice cuánto pesa la acción.

- `.btn .btn-primary`: la acción principal de la pantalla (fondo `ink`, texto `surface`). Una por zona.
- `.btn .btn-accent`: llamada puntual de marca en `shu` (p. ej. «Crear un proyecto» en la bienvenida). Texto blanco sobre `shu` da 3.7:1: úsalo solo con texto medium y sin abusar.
- `.btn .btn-outline`: acción secundaria sobre `paper` o `surface`.
- `.btn .btn-ghost`: acciones terciarias, cerrar, cancelar, iconos.
- `.btn .btn-danger`: borrar o quitar, en `coral`. Los borrados se pueden deshacer, así que no necesitan confirmación.
- `.btn-sm`: 28px de alto, dentro de tarjetas y paneles.

El consumidor aporta la etiqueta (verbo + objeto: «Crear tarea») y, si hay, un icono de 14–16px antes del texto. Desactivado: opacidad 40 %.
