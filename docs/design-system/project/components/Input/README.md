# Input

Campo de texto o selector de 36px con borde `line`, esquinas `radius-xl` y fondo `surface`.

- Etiqueta encima con `.label` (12px medium, `ink-soft`); el consumidor aporta etiqueta y marcador de posición con un ejemplo real («p. ej. …»).
- Al enfocar, el borde pasa a `ink`.
- El campo principal de un diálogo puede crecer a 44px y 16px.
- El buscador de la barra superior y los filtros son la variante en píldora (`radius-full`).
- En notas, el área de texto usa la familia `hand` a 15px.
