# Enso

Círculo zen trazado a pincel que se completa con el progreso; sustituye a las barras de progreso.

- Trazo principal en `shu` (7px, o 9px por debajo de 48px) sobre una pista punteada de `ink` al 15 %, girado −6°. Un segundo trazo fino al 35 % da textura de pincel.
- A 0 % queda un solo punto, como el punto del logo.
- El porcentaje va dentro en `hand-figure`, a un 24 % del diámetro; en tamaños de 30px se omite y se escribe al lado.
- El consumidor aporta el valor (0–1) y el tamaño. Úsalo para el avance de un proyecto o del trabajo completado; para la carga del equipo usa una barra fina.
