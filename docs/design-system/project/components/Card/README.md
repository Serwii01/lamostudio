# Card

Superficie `surface` con borde `line` y esquinas `radius-2xl` sobre el fondo `paper`; agrupa un bloque de contenido.

- Encabezado: `.card-title` y, si ayuda, una nota a mano en `hand` a 14px y un `.count`.
- Filas separadas por divisores `line` al 60 %, con relleno `space-3` vertical y `space-5` lateral.
- Sin sombra en reposo; `shadow-hover` solo si la tarjeta entera es un enlace.
- No anides tarjetas dentro de tarjetas: dentro, usa fondos `ink` al 4 % para separar.
