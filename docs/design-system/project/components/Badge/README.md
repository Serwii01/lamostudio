# Badge

Insignia de estado: punto y palabra sobre el tono suave de su color.

| Variante | Tokens | Estados |
| --- | --- | --- |
| `badge-neutral` | `ink-soft` sobre `ink` 5 % | Por hacer, Borrador, Cerrado, prioridad baja |
| `badge-ocean` | `ocean` / `ocean-soft` | En curso, Planificación |
| `badge-honey` | `honey` / `honey-soft` | En revisión, Pendiente de cliente |
| `badge-moss` | `moss` / `moss-soft` | Hecha, Aprobado |
| `badge-plum` | `plum` / `plum-soft` | En producción |
| `badge-coral` | `coral` / `coral-soft` | Cambios solicitados, bloqueada |

Siempre con texto: el color nunca va solo. `coral` sobre `coral-soft` da 3.9:1, por eso la etiqueta va en peso medium. En la app la marca «bloqueada» lleva el icono de candado en lugar del punto.
