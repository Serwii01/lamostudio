# Kbd

Tecla de atajo: caja de 20px con borde `line` y esquinas `radius-md`.

- Combinaciones: una tecla junto a otra (`Ctrl` `K`; en Mac `⌘`). Secuencias: «luego» entre teclas (`G` luego `P`).
- Úsalo en la chuleta de atajos, en la paleta de comandos, en la barra lateral y dentro de textos de ayuda.
- Todo atajo debe tener también un botón visible: la tecla es un atajo, no el único camino.
