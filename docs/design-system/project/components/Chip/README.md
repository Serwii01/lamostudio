# Chip

Píldora para filtrar una lista o elegir una opción entre pocas.

- `.chip` en reposo; `.chip .chip-active` la opción elegida (fondo `ink`).
- Puede llevar un contador al 60 % de opacidad detrás de la etiqueta.
- El consumidor aporta la etiqueta y el estado activo. Úsalo para filtros (Todas, Con retraso…) y para conmutadores de dos o tres opciones (Mías / Todo el equipo).
- No uses chips para acciones: para eso está Button.
