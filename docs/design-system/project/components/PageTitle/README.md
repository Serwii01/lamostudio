# PageTitle

Cabecera de página: versalitas de contexto, título con subrayado a mano en `shu` y una frase en letra manuscrita.

- `.eyebrow` arriba (fecha, sección o «Todos los proyectos»).
- `.page-title`: `page-title` (32px, Helvetica Light) con el garabato de 72 × 10px debajo, alineado a la izquierda.
- Debajo, una frase en `lead` (Helvetica Light 16px, `ink-soft`) que resume la página con un tono cercano.
- Una sola por página. El consumidor aporta el título y la frase.
